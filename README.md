# AngelCandle

Nuovo e-commerce AngelCandle basato su **WordPress + WooCommerce**.

## Architettura

- **WordPress**: CMS e base applicativa.
- **WooCommerce**: catalogo, varianti, stock prodotti finiti, carrello, checkout, clienti, ordini, pagamenti e spedizioni.
- **angelcandle-theme**: tema custom del frontend AngelCandle.
- **angelcandle-core**: funzionalita specifiche del progetto, incluse personalizzazioni, richieste eventi/bomboniere e, quando necessario, magazzino materie prime/distinte base.

## Principio

Il core WordPress, gli upload e i plugin di terze parti non vengono versionati. La repository contiene il codice proprietario AngelCandle.

## Stato

Bootstrap iniziale del nuovo progetto.
