# Angel Candles — tema WordPress

## Installazione

1. Comprimi la cartella `angel-candles` in formato ZIP.
2. In WordPress apri **Aspetto → Temi → Aggiungi nuovo → Carica tema**.
3. Carica lo ZIP e attiva **Angel Candles**.
4. In **Aspetto → Menu**, assegna un menu alla posizione “Menu principale”. Se non viene assegnato, il tema usa automaticamente le voci della homepage.

La homepage usa `front-page.php`; immagini e CSS sono già inclusi nel tema.
